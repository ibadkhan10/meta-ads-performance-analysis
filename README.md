# Meta Ads Campaign Performance Analysis

## Project Overview
This project analyzes Meta Ads campaign performance using Python and Microsoft Excel. It focuses on data cleaning, exploratory data analysis, advertising metrics, and business insights.

## Project Objectives
- Analyze advertising campaign performance.
- Clean and preprocess datasets.
- Identify important advertising metrics.
- Understand campaign performance.
- Generate meaningful business insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Microsoft Excel

## Project Files
1. META_ads_dataset_data_cleaning_insight_eda.ipynb
2. Meta_ads_Insights_Reporting - PIVOT Ad Level Metrics.csv
3. meta_ads_with_json_dataset_sample.xlsx

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis (EDA)
5. Campaign Performance Analysis
6. KPI Analysis
7. Business Insights

## Key Performance Metrics
- Ad Spend
- Impressions
- Clicks
- Click-Through Rate (CTR)
- Cost Per Click (CPC)
- Conversions
- Return on Ad Spend (ROAS)

## Key Findings
The project focuses on evaluating Meta Ads campaign performance through data cleaning, exploratory data analysis, and advertising metrics.

- Identifies patterns and trends in advertising campaign performance.
- Examines ad-level metrics to understand advertising effectiveness.
- Highlights the importance of monitoring impressions, clicks, ad spend, and conversions.
- Uses performance indicators such as CTR, CPC, and ROAS to evaluate marketing efficiency.
- Demonstrates how data cleaning and analysis can support better advertising decisions.
- Provides a foundation for identifying underperforming campaigns and potential optimization opportunities.
